User Manual 
Municipal financial management system
1.	How to start the system’
Once you start the system, The first thing the user see’s is the Main menu

2.	The Employee Management 
From the main menu the user will have options to select from, Options include -Add an Employee – Display an employee and search for an employee 
3.	The budget management. the user will an option to select from -Enter budget -Enter expenditure and display the budget 
4.	The supplier management. the user will have an option to select from -add supplier – display supplier – and search for suppliers
5.	The asset management. the user will availably options to select from. Add asset – display asset and search for an asset 
6.	The report, at this stage the user will have one option which is to view the report, which display information from each system module 
7.	Exit. the last option from the mane, which closes the system
